# v0.22.4 — unpublished

This source version prepares a matched `millrace-ai`, `millrace-plus`, and
`millrace` bundle at 0.22.4 with Millforge 0.1.1. It has not been published.
Use the published 0.22.3 bundle unless you are validating retained candidate
wheels. A source version and a successful build do not establish release
qualification.

## Included changes

- An explicitly selected Pi RPC runner with pinned executable/profile inputs,
  the existing compiled authority and budget boundaries, and foreground
  command settlement through the v2 POSIX process-group observer.
- Plus's opt-in `lad.full.pi` workflow and its component-free payload-capacity
  contract, retaining the existing domain and evidence obligations.
- Repairs to completed-run enqueue replay and shared adapter startup checks.
- Exact installation evidence, separate setup/demo consent, and the isolated
  zero-key demo with recovery, cancellation and cleanup.

The six existing public Plus workflows remain. The package also contains the
private demo entry used by `millrace demo` and the opt-in Pi LAD entry. Millforge
is not upgraded. Store 11 and plan 18 remain unchanged from published v0.22.3;
older incompatible stores still require fresh state rather than migration.

## Evidence and release boundary

Predecessor private Core/Plus artifacts passed installed scripted-provider
checks on Darwin and one pinned Ubuntu 24.04 x86_64 host, including a five-stage
Pi coding route with a real failing-test/edit/passing-test sequence. This does
not prove all seventeen LAD stages, actual model efficacy, or provider token
accounting. The trusted process-group profile does not contain arbitrary
escaped descendants; active native Pi controls and owner-loss reattachment
remain unsupported.

Actual Bonsai/Qwen profile qualification, final matched artifact validation,
immutable publication pins and public-index verification remain required.
No OS/provider gate or complete local-inference application milestone is
promoted by this component release. See [Pi configuration](../pi-runner.md),
[setup](../setup.md), and [compatibility](../v0.22-compatibility.md).
