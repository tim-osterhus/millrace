# Documentation Freshness Matrix

Use this matrix during release review and source-area changes to decide which
docs need a freshness check. A check does not mean every listed doc must change;
it means the reviewer should confirm the doc still describes the shipped
behavior, public contract, or operator workflow.

Skill columns name the public agent skill docs that need special attention when
source changes affect agent behavior:

- Operator skill: `../skills/millrace-ops-agent-manual/SKILL.md`
- Loop authoring skill: `../skills/millrace-loop-authoring/SKILL.md`

## Review Notes

- Optional `millrace-web` docs remain separate from base runtime docs. Runtime
  docs may mention web read surfaces, but `packages/millrace-web/README.md` and
  `packages/millrace-web/docs/README.md` own dashboard usage.
- Keep `../source-package-map.md` current when source ownership moves, public
  compatibility facades change, or package boundaries change.
- Keep `../doc-index.md` and `codebase-stewardship.md` links in sync after this
  standalone page is integrated by the orchestrator.
