# Closure Request Overflow Invariant Matrix

Closure request overflow is a compiled route for closure requests above the
inline request limit. The durable closure request keeps the complete sealed
snapshot. Dispatch replaces only the `closure_evidence_snapshot` member with a
compact `closure_evidence_overflow` projection, and the session materializes
read-only pages before start. Capacity exhaustion becomes a durable,
operator-required closure capacity block rather than a daemon stop.

Tests are Core tests under `tests/` unless a row names a Plus test. Plus test
paths are relative to `/Users/timinator/Desktop/Millrace-Dev/`. A cell marked
`N/A` states why a column does not apply. A cell marked `GAP` names what no
exact test covers.

Missing accepted artifact outputs on advancing history are refused before CAS
puts. Same-frontier candidates retain the established stale-state refusal.
Existing corrupt-observation failures retain their separately tested forensic
CAS behavior; an unreferenced forensic object is not accepted workflow state.
Full relation validation precedes daemon and runtime-row mutations.
