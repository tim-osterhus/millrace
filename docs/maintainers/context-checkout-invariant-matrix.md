# Context-Checkout Invariant Matrix

This matrix records executable conformance evidence for the generic context
binding, immutable checkout, runner-session, Codex routing, and writeback
slice landed by GSW-01 through GSW-07. Context is selected workflow authority;
the base runtime does not infer a checkout from a workflow name, stage name,
or ambient workspace directory.
