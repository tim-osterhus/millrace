# Daemon Budget Invariant Matrix

This matrix records executable acceptance evidence. Aggregate suite success is
not a substitute for an exact selector. Daemon budgets are operator-selected
runtime authority over an already compiled and admitted plan, so compiler rules
are N/A unless a row says otherwise.
