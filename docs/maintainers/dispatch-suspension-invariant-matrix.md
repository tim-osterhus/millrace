# Dispatch Suspension Invariant Matrix

This matrix covers the schema-9 global dispatch suspension contract. Operator
suspension is distinct from workflow-authored `PauseRecord` state. It gates
only acceptance of new claims; accepted runs and their runner sessions retain
authority.
